# Circle-DailyWeekly

Ежедневные и еженедельные задания WoW Circle в отдельном окне.
**Questie не нужен.**

Если Questie у вас стоит, есть версия, которая показывает то же самое прямо в
его трекере: [QuestieCircle](https://github.com/sanyozeko/QuestieCircle).
Ставить оба аддона сразу не нужно — они делают одно и то же.

## Что умеет

- **Показывает, что задание можно взять** — по строке на группу, ежедневную и
  еженедельную. Выполненное гаснет и возвращается после сброса.
- **Помнит выполнение на весь аккаунт.** Сдал на одном персонаже — видно на
  всех. Одно задание из группы закрывает всю группу до сброса.
- **Показывает, у кого лежит задание** — `Нардол - рейда: 3/5` под строкой.
- **Открывает меню по клику.** Не взято — нужный раздел `.menu`. Выполнено —
  сразу окно сдачи. У этих заданий нет NPC, только меню.
- **Напоминает** при входе в игру и раз в N минут. В бою молчит.
- **Выглядит как трекер Questie** — прозрачный фон, та же типографика и
  отступы. Шрифт, размеры, цвета и поля взяты из исходников Questie,
  а не подобраны на глаз.

## Установка

1. Скачать архив со страницы
   [Releases](https://github.com/sanyozeko/Circle/releases/latest)
   — папка внутри уже названа правильно.
2. Распаковать в `<папка игры>\Interface\AddOns\` так, чтобы получилось
   `Interface\AddOns\Circle-DailyWeekly\Circle-DailyWeekly.toc`
3. **Полностью перезапустить игру** — новую папку аддона `/reload` не подхватит.

Проверить: `/circle status` в игре.

## Команды

| Команда | Что делает |
|---|---|
| `/circle` | показать или скрыть окно |
| `/circle status` | состояние, кто что держит, время сбросов |
| `/circle take` | открыть меню для того, что доступно |
| `/circle daily` / `/circle weekly` | открыть конкретный раздел |
| `/circle done daily` | отметить выполненным вручную |
| `/circle undone weekly` | снять отметку |
| `/circle remind 30` | напоминать раз в 30 минут, `0` — выключить |
| `/circle sound` | звук напоминания |
| `/circle lock` | закрепить окно на месте |

Короткий вариант команды — `/cdw`.

Ручная отметка нужна редко: если игра упала сразу после сдачи или задание сдали
ещё до установки аддона. Сервер не сообщает о сданных **ежедневных** заданиях
(о еженедельных — сообщает), поэтому восстановить такое автоматически нельзя.

## Настройка

Список заданий — таблица `ns.QUESTS` вверху `Core.lua`.
День недельного сброса — `WEEKLY_RESET_WDAY` там же (сейчас среда).

## Ограничения

- Срез персонажа пишется при выходе или `/reload`; персонажи, которыми не
  заходили после установки, невидимы.
- Ежедневный сброс берётся с сервера, недельный вычисляется от него по дню
  недели. Если сервер сменит расписание, поправьте константу.
